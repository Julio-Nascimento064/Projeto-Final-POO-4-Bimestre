# Sistema de Gerenciamento de Livraria

Este projeto foi desenvolvido em Python com foco em Programação Orientada a Objetos (POO) e tem como objetivo simular o funcionamento de uma livraria. A aplicação permite registrar pessoas, usuários, funcionários, livros, empréstimos e cálculos de multa, além de conter um menu interativo para realizar operações básicas do sistema.

## Tema do projeto

O sistema representa uma livraria digital onde é possível:

- cadastrar usuários e funcionários;
- registrar livros do acervo;
- realizar empréstimos de livros;
- verificar disponibilidade dos itens;
- calcular multas estimadas por atraso;
- consultar a média de livros por empréstimo;
- buscar livros por índice na lista cadastrada.

A estrutura do código foi organizada por classes, como `Pessoa`, `Usuario`, `Funcionario`, `Livro` e `Emprestimo`, demonstrando os conceitos principais de encapsulamento, herança, composição e métodos de validação.

## Como executar o projeto

O programa é interativo, então ele deve ser executado em um terminal ou prompt de comando, não em um ambiente sem entrada do usuário.

1. Abra o terminal ou prompt de comando.
2. Acesse a pasta do projeto:

```bash
cd "C:\Users\julio\Documents\Projeto-Final-POO-4-Bimestre"
```

3. Execute o arquivo principal:

```bash
python projetofinal.py
```

Se o Python estiver configurado como `py` no ambiente Windows, também pode usar:

```bash
py projetofinal.py
```
